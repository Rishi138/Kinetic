# Kinetic — ACL Recovery Movement Analysis System

Kinetic is a real-time computer vision system built to address the lack of objective feedback in home physical therapy after ACL reconstruction, meniscectomy, and knee fracture. Using MediaPipe Pose, it analyzes movement quality during rehab exercises and computes knee valgus, hip drop, trunk lean, Limb Symmetry Index (LSI), and longitudinal compensation trends across recovery sessions — giving patients and clinicians objective signal on form and progress between in-person PT visits, not just during them.

For the clinical and technical background behind these metrics and design choices, see [Supporting Research](sources.md).
